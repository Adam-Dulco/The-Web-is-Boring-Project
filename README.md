- Internet Browser
- Mouse and Keyboard
- Monitor
- Visual Studio Code (VS Code)
- Live Server Extension (Ritwick Dey)

## Entering the Website

> **Note:** To ensure the 3D elements load correctly, open the project through VS Code using the Live Server extension.

To access the website, follow these steps:

1. Open the project folder in VS Code.
2. Select the "index.html" file.
3. Select "Go Live" in the bottom right corner (If you do not see this, please install the "Live Server" extension by Ritwick Dey and reload the page to try again).
4. Ensure the landing page is visible (double doors).
5. Read the provided disclaimer (Important Notice).
6. If you have read the disclaimer and wish to proceed, click "I have read this & accept entrance". Otherwise, do not enter the website.
7. Click the "Enter" button in the middle of the page to enter the website.

## Exiting the Website

To exit the website, simply click the "Exit" button located in the bottom right area of the screen.

## Using the Navigation Panel (Getting from page to page)

To use the navigation panel, click the button for the page you want to visit. You will be taken there.

## Viewing Page Content

Several pages of the website can be scrolled vertically, which may not be immediately obvious.  
The pages that can be scrolled vertically are:

1. TV & Radio Press Packs
2. Christopher Roby Film Archive
3. The Bradshaws Collection
4. The Chloe Fisher Midwifery Collection
5. Edge Hill University & Predecessors

To scroll these pages, simply scroll down using the mouse or press the down arrow key on your keyboard.

## Using the Return to Landing Destination Button

To return to the top of a vertically scrollable page, scroll to the bottom of the page and click the "Return to Landing Destination" button.

## Donating to the Archive

To "donate" to the Archive, visit the **Donating** page and click the box on top of the desk labeled **Donate**.

> **Note:** This does not actually donate to the archive—it is purely for user enjoyment and interactivity.

## Using the About Page & Time Warp Feature

To use the About page, scroll horizontally using the mouse:

- Scroll up to move left
- Scroll down to move right

The "Time Warp" feature, located near the bottom centre of the page, can be activated by clicking it. This will rotate the page content and randomly stop on a different section.

## Interacting with the 3D Tank Model

To interact with the 3D tank model, which appears on the "The Bradshaws Collection" page when you enter it:

1. Wait for the tank to come to a complete stop.
2. Click and hold the left mouse button, then drag the tank model in any direction.

> **Note:** The tank can also be resized and moved across the screen by clicking and holding the right mouse button.
